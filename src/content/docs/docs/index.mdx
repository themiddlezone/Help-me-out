These guides take you from a stock Samsung phone to a custom ROM, step by step. Read each one through before you
start typing commands. Most problems come from a skipped step, not from the build.

<Aside type="caution" title="Check your model first">
  Every guide here is for the **Galaxy A12 SM-A127F** (Exynos 850, codename `a12s`). The MediaTek Galaxy A12
  (SM-A125F) is a different phone inside and these files will not work on it.
</Aside>

## Where the files are

Downloads live on the [Galaxy A12 page](../a12s/). Every file there links straight to the GitHub release it came from
and lists its SHA-256 checksum, so you can check a download before flashing it.

Stuck? The [FAQ](../faq/) covers the common questions, and [Support](../support/) has the ways to reach a person.
