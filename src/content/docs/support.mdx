## Report a bug

A good report gets fixed much faster. Include:

- **Your model number**, from Settings, About phone.
- **The exact build**, for example `Release 1 (rom38)` or the kernel version.
- **What you did, what you expected and what happened.** Steps to make it happen again are gold.
- **Logs**, if you can get them. With USB debugging on, run these on your computer right after the problem shows up:

  ```sh
  adb logcat -d > logcat.txt
  adb shell dmesg > dmesg.txt
  ```

  `dmesg` needs root on most builds. Send the `logcat.txt` anyway if it does not work.

Check the **Known issues** in the release notes first, your bug might already be on the list.

## Help the project

- **Try the test builds** and report what breaks.
- **Share the site** with other Galaxy A12 owners.
- **Fix something.** The guides on this site can be edited on GitHub, and the build trees live under
  [a12s-dev](https://github.com/a12s-dev).
